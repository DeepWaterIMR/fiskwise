# Fiskwise agent entry point

Read [AGENTS.md](AGENTS.md). A request to `install https://github.com/DeepWaterIMR/fiskwise`,
`check Fiskwise`, `update Fiskwise`, or `uninstall Fiskwise` selects its full lifecycle skill. Follow that
skill; the user does not need to paste implementation details. Register this host using
[the agent discovery profiles](docs/AGENT-SUPPORT.md). Do not stop after copying skill files.
