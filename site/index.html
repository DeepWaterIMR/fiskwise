01 / THE KNOWLEDGE PACKS

Expertise for each stage
of the work.

Choose a pack for the task in front of you. Use it independently, or combine packs across a research workflow.

Knowledge packs are instructions, methods, practical tools, and review procedures that agents read at runtime. They support tools such as Claude Code and Codex; they are not trained models.

02 / SHARED R TOOLS

R tools for
fisheries science.

Fiskwise checks ggOceanMaps and ggFishPlots during runtime setup and updates them with your package permission. They also work independently; use their documentation for mapping and life-history methods.

03 / GET STARTED

Start with a question.
Choose the right pack.

Begin with the shared writing and presentation workflows. Fiskwise checks the shared R toolchain and packages with permission; add specialist data and modelling packs when needed.

  1. 01

    Choose your task

    Biotic data → BAIT. Survey indices → index-wise. SPiCT assessment → spict-wise. Documents → wise-writing. Slides → wise-presentations.

  2. 02

    Install the pack once

    Open the selected pack’s README with your agent and follow its installation workflow. Modelling packs may require supporting packs and R packages.

  3. 03

    Direct the work and review the result

    Set the scientific question, confirm assumptions, inspect code and diagnostics, and evaluate the conclusions. Agent output requires human review.

WHY FISKWISE?

Domain knowledge,
made reusable.

The name combines FISK — Fisheries Intelligence Skill Kit — with wise, reflecting the domain knowledge and understanding the ecosystem gives to an AI agent. It also draws on fisk, the Scandinavian word for fish, and fiskeri, meaning fishing or fisheries.

Developed at the Institute of Marine Research, Norway, Fiskwise includes tools for IMR data formats alongside knowledge and software useful to the wider scientific community.

As methods and workflows improve, version-controlled resources let those improvements travel between projects, researchers, and AI agents.
