FISKWISE / GETTING STARTED

Install only what your research needs.

Fiskwise is a collection of independent, inspectable knowledge packs and R tools. Its install, update, and removal workflows are built into the agent instructions. Start with writing and presentations, then add tools and specialist packs when needed.

01 / CORE KNOWLEDGE

Start with writing and presentations

These packs provide reusable scientific-writing conventions and a planning, authoring, and visual-review workflow for Quarto slides. They do not install R packages or a model by themselves.

Install Fiskwise

install https://github.com/DeepWaterIMR/fiskwise

You can also select the prompt and copy it with your keyboard.

Each ordinary source commit increases the patch version by 0.0.1 and records its update date. Minor and major increases require your explicit request. Knowledge packs use VERSION; R packages use DESCRIPTION. Shared version policy.

02 / ADD ONLY WHEN NEEDED

Shared R tools, specialist packs on demand

Core skills install before R is needed. Runtime setup checks tidyverse, writing/presentation dependencies, ggOceanMaps and ggFishPlots. Package installation requires saved, revocable permission; system changes need separate approval. BAIT and modelling packs are optional.

R, tidyverse, and Quarto

Install these only when a project needs them and you approve. Quarto CLI is a separate application; the R package quarto is its R interface and does not replace the CLI.

Maps and life-history plots

ggOceanMaps and ggFishPlots are independent R packages. Fiskwise checks their GitHub versions during runtime setup and updates them with package permission. Additional map data and analysis choices remain task-specific.

IMR Biotic data

Install BAIT only for IMR Biotic work. Keep raw records and exact station positions local. Follow BAIT privacy guidance and use the database path in its config unless you explicitly select another local database.

Model workflows

Add index-wise or spict-wise for a relevant analysis, with their stated pack and R-package prerequisites. gadget-wise is planned; it is not installable yet.

Before saving consent: ask which named software may be installed in future, explain the stored preference and how to revoke it, and keep consent separate from permission to read or move research data.

03 / MAINTAIN YOUR SETUP

Install, update, or remove Fiskwise

Copy a short command into Claude Code, Codex, Antigravity, or Mistral Vibe. These agents can follow the workflow when they have GitHub access and local filesystem and shell access; browser-only assistants cannot complete local setup. The install workflow sets up core packs first, checks R, Quarto and tidyverse, requests permission for package or system changes, offers BAIT for IMR Biotic work, and leaves model packs optional. Removal asks you to confirm before deleting files. Agent compatibility details.

Update Fiskwise

update Fiskwise

You can also select the prompt and copy it with your keyboard.

Uninstall Fiskwise

uninstall Fiskwise

You can also select the prompt and copy it with your keyboard.

04 / SCOPE AND REVIEW

Research guidance, under researcher direction

Fiskwise describes scientific workflows and methods; each pack has its own domain and prerequisites. It is not a trained model, an institutional policy, or a substitute for project-specific protocols, applicable standards, or expert review.

For a task that allows delegation, ask for the least costly capable model and report the full task cost: setup, model calls, data handling, review, reruns, and researcher time. Keep sensitive data local and do not delegate access beyond the approved scope.
