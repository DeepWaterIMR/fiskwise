FISKWISE / GETTING STARTED

Tell your agent what you want to do.

Fiskwise is a collection of independent, inspectable knowledge packs and R tools. Its install, update, and removal workflows are built into the agent instructions. Start with wise-writing and the shared R tools, then add data, presentations and methods when needed.

02 / ADD ONLY WHEN NEEDED

Shared R tools, specialist packs on demand

Core skills install before R is needed. Runtime setup checks tidyverse, writing dependencies, ggOceanMaps and ggFishPlots. Package installation requires saved, revocable permission; system changes need separate approval. BAIT and modelling packs are optional.

R, tidyverse, and Quarto

Install these only when a project needs them and you approve. Quarto CLI is a separate application; the R package quarto is its R interface and does not replace the CLI.

Maps and life-history plots

ggOceanMaps and ggFishPlots are independent R packages. Fiskwise checks their GitHub versions during runtime setup and updates them with package permission. Additional map data and analysis choices remain task-specific.

IMR Biotic data

Install BAIT only for IMR Biotic work. Respect the data owner’s access and sharing conditions, especially for Russian and reference-fleet data. Follow BAIT privacy guidance and use the database path in its config unless you explicitly select another local database.

03 / MAINTAIN YOUR SETUP

Install, update, or remove Fiskwise

Copy a short command into Claude Code, Codex, Antigravity, or Mistral Vibe. These agents can follow the workflow when they have GitHub access and local filesystem and shell access; browser-only assistants cannot complete local setup. The install workflow sets up core packs first, checks R, Quarto and tidyverse, requests permission for package or system changes, and offers the add-ons your task needs. Removal asks you to confirm before deleting files. Agent compatibility details.

update Fiskwise

04 / SCOPE AND REVIEW

Research guidance, under researcher direction

Fiskwise describes scientific workflows and methods; each pack has its own domain and prerequisites. It is not a trained model, an institutional policy, or a substitute for project-specific protocols, applicable standards, or expert review.

Researchers direct and remain responsible for the work. Review methods, results and citations, and disclose AI use as required by the intended publication. ICMJE guidance on AI use.
